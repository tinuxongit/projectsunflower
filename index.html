    Getting started

    Windows

    1. Open from your downloads.
    2. If Windows says it protected your PC, press More info, then Run anyway. The launcher isn't signed yet.
    3. The launcher moves into the game's own folder and adds Project Sunflower to the Start menu. You can delete the download.

    Linux

    1. Right-click in your downloads, open Properties and allow it to run as a program.
    2. Open it.
    3. The launcher moves into the game's own folder and adds Project Sunflower to the app menu. You can delete the download.

    Sign in on the launcher and press Play. It installs the game and keeps the game and itself up to date. To remove everything, press Uninstall in its settings.
