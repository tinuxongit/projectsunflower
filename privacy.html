Privacy

Last changed on 5 October 2026

Project Sunflower is made by tinux. This page lists everything the game and this website keep about you. There are no ads, no trackers and no analytics, and nothing is sold or shared with anyone.

Your account

When you sign up, the game server keeps

  • your username and the date you signed up
  • your password, stored as a scrypt hash, so nobody can read it back
  • your character's name and look, and the skins you upload
  • the items your character holds
  • which server you are playing on while you play

You don't give an email address or your real name. If an admin bans or mutes your account, the reason and the end date are kept with it.

Signing in

Signing in gives your computer a token that keeps you signed in for 30 days. The launcher saves it in the game's folder on your computer. If you forget your password, an admin can give you a reset code, which works for 24 hours.

Chat

The server passes your chat messages to the players who can see them and does not save them. Words on the chat filter are hidden before anyone sees them.

Your internet address

The server uses your internet address to limit how often one place can sign up, guess passwords or send crash reports. It holds the address in memory for at most an hour and never writes it down.

Crash reports

If the game crashes, it sends the log of that run to the game server the next time it starts. The log holds the game engine's version, your graphics card, the game's error messages and where in the game's code the crash happened. The game replaces your home folder's name with ~ before sending, so your computer's user name stays out of it. Your username is added when you are signed in. Each server keeps its newest 200 crash reports, and tinux reads them only to fix the game.

Who handles it

The game servers run on a computer tinux owns. Traffic to them and to this website goes through Cloudflare, which sees your internet address as it passes. Admins of the game can see usernames, character names and moderation notes.

This website

This website sets no cookies. It asks the game server for the newest version and the news, and nothing else.

Seeing or deleting your data

Ask tinux through Discord or tinux.dev to see what is kept about you, or to delete your account and everything tied to it.
